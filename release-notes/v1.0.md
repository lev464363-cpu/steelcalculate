Первый релиз калькулятора волочения для Windows: запускается без установленного Python.

**Как запустить:** скачай архив ниже, распакуй в любую папку и дважды щёлкни «Калькулятор волочения.exe». Рядом лежат папка `data` (справочники, правятся в Блокноте) и `ПРОЧТИ.txt`. Если Windows предупредит о неизвестном издателе — «Подробнее → Выполнить в любом случае».

## Что нового по сравнению с версией 8.2

**Расчёт**
- Противонатяжение в формуле Зибеля (по Заксу); мощность барабана — с учётом противонатяжения следующего прохода.
- Ручной ввод σт/σв и прочности после отжига.
- Требование к прочности готовой проволоки по ГОСТ/ТУ — проверка в маршруте, отметка в PDF техкарты.
- Оптимизатор учитывает выбранный стан (барабаны, паспортная скорость, двигатель каждого барабана), скорость этапов — 5–15 м/с.
- Двигатель барабана по умолчанию — 52 кВт.

**Производство**
- Карта оператора (PDF): барабаны, волоки, номера фильер из журнала, скорости, графы для замеров.
- Запись партии в журнал фильер, фактическая стойкость снятых фильер — в себестоимость.
- Свои допуски: НТД, диаметр, отклонения и примечание — на каждый диаметр своя строка.

**Надёжность**
- Повреждённые файлы пользователя не затираются, а откладываются в резервную копию; запись — атомарная.

**Под вопросом** (сверить с практикой): σт ≈ 0,85·σв, формула Зибеля, нагрев k = 0,9; смазка и прочие материалы в маршруте с отжигами считаются по этапам.
